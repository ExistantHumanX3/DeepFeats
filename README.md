# bv_game_jam
A game jam for the blue valley school district

HOW TO INSTALL:


Controls:
WASD/Arrow keys: move
M1: Use weapon
Ammunition automatically reloads every 15 seconds.
You can take up to 3 hits before dying.

You are a ghost trying to escape Hell because all they eat is candy corn and you hate candy corn. People who like candy corn belong in hell. Go use these weapons you stole.
